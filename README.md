## 🆓 ال API المجاني المستخدم (هذا اللي طلبته!)

### 1️⃣ TheSportsDB (الأساسي - لا يحتاج مفتاح)

- **الرابط:** https://www.thesportsdb.com/documentation
- **السعر:** **مجاني 100%** 🎉
- **التسجيل:** **غير مطلوب** (نستخدم المفتاح التجريبي `3`)
- **المحتوى:** نتائج لايف، مواعيد، فرق، شعارات، بطولات من كل العالم
- **Endpoints المستخدمة في المشروع:**
  ```
  https://www.thesportsdb.com/api/v1/json/3/livescore.php?s=Soccer
  https://www.thesportsdb.com/api/v1/json/3/eventsday.php?d=YYYY-MM-DD&s=Soccer
  ```

### 2️⃣ API-Football (اختياري - لمزيد من البيانات)

إذا أردت دقة أعلى في الإحصائيات:
1. ادخل https://rapidapi.com/api-sports/api/api-football
2. سجل مجاناً (Free plan = 100 طلب/يوم)
3. انسخ مفتاحك وضعه في `app.js`:
   ```js
   RAPIDAPI_KEY: 'ضع_مفتاحك_هنا',
   ```

## 🧠 كيف يعمل محرك التوقع؟

الخوارزمية تحسب الاحتمالات بناءً على:

```
1. القوة الأساسية للفريق (من اسمه - الفرق الكبيرة لها وزن أعلى)
2. ميزة الملعب (+5% للمضيف)
3. النتيجة الحالية × الوقت المتبقي
   → كلما اقتربت النهاية، الفارق الحالي يزيد تأثيره
4. الأهداف المتوقعة = (معدل أهداف/دقيقة) × الدقائق المتبقية
5. نسبة الثقة = الفرق بين أعلى احتمال والثاني
```

### مثال عملي:
- **ريال مدريد 2-1 برشلونة** في الدقيقة 67
- المضيف متقدم + وقت قليل متبقي → احتمال فوز المضيف يقفز لـ 68%
- الهدف المتوقع = 2 + (3 أهداف/67 دقيقة × 23 دقيقة) ≈ 3.2
- التوقع: **ريال مدريد يفوز (68%) + Over 2.5 + BTTS: نعم**
